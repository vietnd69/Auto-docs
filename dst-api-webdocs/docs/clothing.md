# Clothing

> Based on game build **714014** | Last updated: 2026-03-20

## Overview

The `clothing.lua` file serves as a central data repository for all clothing and skin assets in Don't Starve Together. It is automatically generated by `export_accountitems.lua` and contains no executable logic, functioning purely as a lookup table. The file maps clothing asset IDs to their respective configurations, such as slot type (body, feet, hand, legs), rarity, release group, and symbol override data. Systems requiring clothing information iterate over this table to resolve asset properties and apply visual overrides during runtime. Because this file is data-only, it does not define component methods, events, or stateful properties.

## Usage example

```lua
-- Load the clothing data table from the script directory
local clothing_data = require("clothing")

-- Iterate through definitions to find specific types
for id, config in pairs(clothing_data) do
    if config.type == "BODY" then
        -- Process body clothing items
        print("Processing body slot: " .. id)
    end
end

-- Access symbol overrides for build configuration
local overrides = clothing_data["winter_hat"].symbol_overrides
local hides = clothing_data["winter_hat"].symbol_hides
```
